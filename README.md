# ISTQB® CTFL v4.0 Practice Exam 2 (English)

**Status: public draft.** An independent review has been completed. Questions and explanations may still change as feedback is incorporated.

A free, full-length practice exam for the ISTQB® Certified Tester Foundation Level v4.0 exam (syllabus v4.0.1): 40 original questions, a timed exam mode, and a study mode with option-by-option explanations. Each explanation links to the matching section of the free exam guide.

- Exam address: https://kadir-camoglu.github.io/istqb-ctfl-v4-0-1-mock-exam-2-en/
- Companion exam guide: https://kadir-camoglu.github.io/istqb-ctfl-v4-exam-guide/
- The page is a single self-contained file (`index.html`). It works offline; answers and scores are stored only in your browser.
- Feedback: kadir.camoglu@gmail.com

Independent and unofficial. Not affiliated with or endorsed by ISTQB®.
